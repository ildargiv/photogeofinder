โปรแกรมดูรูปฟรีที่เน้นความเป็นส่วนตัว บอกได้ว่า**รูปนี้ถ่ายที่ไหน** อ่าน GPS จาก EXIF แล้วแสดงตำแหน่งบน Google Maps, Yandex Maps และ OpenStreetMap เคียงกัน พร้อมที่อยู่ เวลา กล้อง รูปของบริเวณนั้น และบทความวิกิพีเดียที่อยู่ใกล้เคียง

![ภาพหน้าจอ](docs/screenshots/theme-brand.png)

## ความสามารถ

- **รูปของคุณอยู่กับคุณเสมอ** ไม่มีการอัปโหลด อ่านข้อมูลบนอุปกรณ์ของคุณโดยตรง ไม่ต้องมีบัญชี ไม่มีโฆษณา ไม่มีการติดตาม
- **ดูที่ถ่ายบนแผนที่** Google, Yandex, OpenStreetMap และภาพดาวเทียมในหน้าต่างเดียว
- **ที่อยู่**และพิกัดของทุกรูป พร้อมลิงก์ไปยังภาพพาโนรามาถนน
- **รูปถ่ายบริเวณนั้นจากคนอื่นๆ** และคู่มือจากวิกิพีเดียเกี่ยวกับสิ่งที่อยู่ใกล้เคียง
- **รูปทั้งหมดบนแผนที่เดียว** พร้อมเส้นทางการเดินทางของคุณ
- **เวลาและกล้อง**ที่ใช้ถ่าย แสดงข้างพิกัด
- **ค้นหาสถานที่**ให้รูปที่ไม่มีพิกัด
- **ติดตั้งเป็นแอปได้** และใช้งานแบบออฟไลน์ได้

## ความเป็นส่วนตัว

รูปถูกเปิดและอ่านในเบราว์เซอร์ของคุณ ไม่มีการอัปโหลด ส่งเฉพาะพิกัดของจุดไปยังบริการแผนที่ ที่อยู่ และวิกิพีเดีย ไม่ต้องมีบัญชี ไม่มีโฆษณา ไม่มีการติดตาม

## การติดตั้ง

- ออนไลน์: เปิด https://ildargiv.github.io/photogeofinder/ ใน Chrome หรือ Edge แล้วกด "ติดตั้งแอป" อัปเดตจะมาเองโดยอัตโนมัติ
- ใช้งานในเครื่อง: ดาวน์โหลด zip ล่าสุดจาก [Releases](https://github.com/ildargiv/photogeofinder/releases/latest) แตกไฟล์ แล้วรัน `start-windows.bat` (Windows ต้องมี Python) หรือ `start-mac-linux.command` แอปจะแจ้งเมื่อมีเวอร์ชันใหม่
