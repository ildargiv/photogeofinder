사진이 **어디서 찍혔는지** 보여 주는 무료 개인정보 보호 사진 뷰어입니다. EXIF의 GPS를 읽어 Google 지도, Yandex 지도, OpenStreetMap에 나란히 표시하고 주소, 촬영 시간, 카메라, 주변 사진, 근처 위키백과 문서도 함께 보여 줍니다.

![스크린샷](docs/screenshots/theme-brand.png)

## 기능

- **사진은 내 기기에만 있어요.** 업로드되지 않고 기기에서 바로 읽어요. 계정, 광고, 추적 없음.
- **촬영 장소를 지도에서.** Google, Yandex, OpenStreetMap, 위성 지도를 한 화면에서.
- 모든 사진의 **주소**와 좌표, 그리고 거리 파노라마 링크까지.
- **다른 사람들이 찍은 주변 사진**과 위키백과로 보는 주변 명소 안내.
- **모든 사진을 한 지도에** 표시하고 여행 경로까지.
- 좌표 옆에 **촬영 시간과 카메라** 정보도.
- 좌표 없는 사진은 **장소 검색**으로.
- **앱으로 설치**하고 오프라인에서도 사용.

## 개인정보 보호

사진은 브라우저에서 열고 읽으며 절대 업로드되지 않습니다. 지도, 주소, 위키백과 서비스에는 지점의 좌표만 전송됩니다. 계정, 광고, 분석 없음.

## 설치

- 온라인: Chrome 또는 Edge에서 https://ildargiv.github.io/photogeofinder/을 열고 "앱 설치"를 누르세요. 업데이트는 자동으로 적용됩니다.
- 로컬 버전: [Releases](https://github.com/ildargiv/photogeofinder/releases/latest)에서 최신 zip을 내려받아 압축을 풀고 `start-windows.bat`(Windows, Python 필요) 또는 `start-mac-linux.command`를 실행하세요. 새 버전이 나오면 앱이 알려 줍니다.
