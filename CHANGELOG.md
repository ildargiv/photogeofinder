# Changelog

## 2.0.1
- Fonts are bundled with the app; no requests to Google Fonts.
- Strict Content Security Policy: scripts only from the app itself, network access limited to the map, address, Wikipedia and update services.
- Windows installer (.exe) attached to each release.
- The address is shown in the current interface language after switching languages.

## 2.0.0
- Installable app (PWA) with offline shell and update notifications.
- Brand, light and dark themes; animated splash and start screen.
- 15 interface languages, including Japanese, Korean, Hindi, Indonesian, Vietnamese, Thai and Arabic (right-to-left); app name in the logo follows the language.
- "All photos" map with trip route, time and camera next to coordinates.
- Nearby Wikipedia articles, photos of the area from Wikimedia Commons.
- Privacy first: photos are read on the device and never uploaded.
