免费、注重隐私的照片查看器，告诉你**照片是在哪里拍的**。它读取 EXIF 中的 GPS，把地点同时显示在 Google 地图、Yandex 地图和 OpenStreetMap 上，并给出地址、拍摄时间、相机、当地照片和附近的维基百科条目。

![截图](docs/screenshots/theme-brand.png)

## 功能

- **照片只留在你身边。**不会上传，直接在你的设备上读取。无需账号，没有广告，不做追踪。
- **在地图上看拍摄地点。**Google、Yandex、OpenStreetMap 和卫星图在同一窗口。
- **地址**和每张照片的坐标，并附街景全景链接。
- **他人拍摄的此地照片**，以及维基百科对附近地点的介绍。
- **所有照片在一张地图上**，并显示旅行路线。
- **拍摄时间和相机**显示在坐标旁边。
- **地点搜索**，适用于没有坐标的照片。
- **可安装为应用**，离线也能用。

## 隐私

照片在你的浏览器中打开和读取，绝不上传。只有地点坐标会发送给地图、地址和维基百科服务。无需账号，没有广告，没有统计。

## 安装

- 在线：用 Chrome 或 Edge 打开 https://ildargiv.github.io/photogeofinder/，点击“安装应用”。更新会自动到达。
- 本地版本：从 [Releases](https://github.com/ildargiv/photogeofinder/releases/latest) 下载最新 zip，解压后运行 `start-windows.bat`（Windows，需要 Python）或 `start-mac-linux.command`。有新版本时应用会提示。
