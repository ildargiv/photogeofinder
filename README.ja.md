写真が**どこで撮られたか**を表示する、無料でプライバシー重視の写真ビューアー。EXIF の GPS を読み取り、Google マップ、Yandex マップ、OpenStreetMap に並べて表示します。住所、撮影日時、カメラ、周辺の写真、近くの Wikipedia 記事も表示します。

![スクリーンショット](docs/screenshots/theme-brand.png)

## 機能

- **写真は手元から出ません。**アップロードされることはなく、端末上で読み込まれます。アカウント不要、広告なし、トラッキングなし。
- **撮影場所を地図で表示。**Google、Yandex、OpenStreetMap、衛星写真をひとつの画面で。
- すべての写真の**住所**と座標、ストリートパノラマへのリンクも。
- **ほかの人が撮った周辺の写真**と、Wikipediaによる近くのスポット案内。
- **すべての写真をひとつの地図に**表示し、旅のルートもわかります。
- 座標と一緒に**撮影日時とカメラ**も表示。
- 座標のない写真は**場所検索**で設定できます。
- **アプリとしてインストール**でき、オフラインでも使えます。

## プライバシー

写真はブラウザ内で開いて読み込まれ、アップロードされることはありません。地図・住所・Wikipedia のサービスに送られるのは地点の座標だけです。アカウント不要、広告なし、解析なし。

## インストール

- オンライン：Chrome または Edge で https://ildargiv.github.io/photogeofinder/ を開き、「アプリをインストール」をクリック。更新は自動で届きます。
- ローカル版：[Releases](https://github.com/ildargiv/photogeofinder/releases/latest) から最新の zip をダウンロードして展開し、`start-windows.bat`（Windows、Python が必要）または `start-mac-linux.command` を実行します。新しいバージョンが出るとアプリが知らせます。
